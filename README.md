# AI Resume Analyzer

An AI-powered Resume Screening application built using Python and Streamlit.

## Features

- Resume PDF Upload
- Skill Extraction
- ATS Score Calculation
- Job Description Matching
- Missing Skills Detection
- Skill Recommendations
- Java vs JavaScript Accurate Matching

## Tech Stack

- Python
- Streamlit
- PyPDF2
- Regex
- Git & GitHub

## Run Locally

```bash
pip install streamlit PyPDF2
streamlit run stream_app.py
